CaveViewer advantages

Flexible large map support

CaveViewer builds a local cache rather than loading every chunk and texture at once. This lets consumer-grade hardware load large maps that might otherwise exceed its available memory, while Preferences still lets you adjust the balance for a particular map.

CaveViewer sets working memory budgets from available system and graphics memory. If textures exceed the graphics budget, it selects a smaller size before upload; fine surface detail may look softer.

You can tune import performance by adjusting Import chunk size and Max upload group size preferences. Adjust Cache-building worker limit to speed up or slow down map imports depending on your hardware.

Changes to import settings take effect when a cache is built. Set them before importing a map, or rebuild an existing cache to use new values.

Smooth rendering

As you view a map, the app loads only the map parts required to provide the best viewing experience. You can adjust streaming performance in the Preferences section.

You can tune memory use with System RAM target and GPU memory target, which set how much map data stays resident. Loading worker limit and Loading CPUs to keep free control background work and reserve processor capacity for other apps.

You can save a restriction, landmark, or passage as a portable precompiled map with its geometry and textures. See Help section in the app for more information.

Free software and maps

CaveViewer and its maps are free. There are no accounts, subscriptions, ads, or trackers.
