# Preferences backup and restore

This work item defines a user-facing workflow for sharing, restoring, and
resetting CaveViewer preferences without requiring users to locate or edit the
application's private configuration directory.

## Compatibility decision

The rename to `preferences.json` includes one compatibility bridge for existing
users: a sibling `advanced_settings.json` is renamed once when no
`preferences.json` exists. The current filename always wins when both exist,
and a failed migration must preserve and temporarily read the old file so user
settings are not lost. The older `.caveviewer_advanced_settings.json` name and
all other historical names remain unsupported. Release notes must explain the
new filename, automatic one-time migration, precedence rule, and unsupported
older paths.
